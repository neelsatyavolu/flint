Flint 1.0.0

New since 0.3.0:

- Calendar invitations: a clean invite card with time in your zone, repeats, Join for Meet, Zoom and Teams, guests, conflicts, and Updated and Cancelled states. Yes / Maybe / No updates your Google Calendar or CalDAV calendar (iCloud, Fastmail, others) whichever mail account the invite arrives on, or emails a standard reply to the organizer. Add calendars in Settings > Calendars.
- Verification codes: detected in new mail, shown as a banner, a list chip and a notification with Copy. With Accessibility on, Flint suggests the code next to the code field in any app or browser and types it (Control+Option+V types the newest code). An optional browser extension is under Settings > Verification codes > Advanced.
- Command palette: fuzzy search across commands, mail, people, folders and settings, with nested pages and prefix modes (> / @ #).
- Signatures: one signature can be shared by several accounts; replies start with a single line above the signature.
- Updates: choose Install automatically, Ask before restarting, or Only when I check (Settings > About).
- Read receipts: a grey check when sent, a green double check once read, with counts for several recipients, on list rows and on each sent message.
- A new Home with a scenic background and widgets, a Catch me up summary every 3 hours with +AI, thread list filters, bulk select and drag to the sidebar, a person card, image preview and print in the reader, Not spam, a forgotten-attachment check, Cmd+Shift+Return to send later, Cmd+Z to undo send, text size, and contrast and focus improvements.
- Menus open in place, and many smaller fixes.
