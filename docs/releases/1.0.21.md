Flint 1.0.21

- Images now load in mail from people you haven't trusted yet, as long as each image is the same for every recipient. Flint still holds back any image whose address could identify you, such as one containing your email address, a long tracking id or a per-reader token, and it still removes known tracking pixels. When something is held back, the message says so and "Load all images" brings it in.
- This is the new "Safe images" choice under Settings, Inbox, Remote images, and it is the default unless you picked a setting yourself. "Known senders" keeps the old behaviour. A careful sender can still disguise a per-reader image as an ordinary file, so choose "Known senders" or "Never load" if you want none of that risk.
